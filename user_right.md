## Пользователи системы

Система предназначена для использования разными категориями пользователей:

### Абитуриенты
- получение информации о направлениях подготовки;
- количество бюджетных и платных мест;
- статистика прошлых лет (в агрегированном виде);
- сроки подачи документов;
- средний проходной балл прошлых лет.

### Студенты
- просмотр собственной успеваемости;
- средний балл за семестр;
- наличие академических задолженностей;
- список дисциплин текущего семестра;
- расписание занятий.

### Преподаватели
- список своих дисциплин;
- количество студентов в группах;
- средний балл по дисциплине;
- процент неаттестованных;
- учебная нагрузка по семестрам.

### Сотрудники и администрация
- численность студентов по факультетам;
- статистика приёма;
- динамика набора по годам;
- отчётность по кафедрам;
- заполняемость аудиторного фонда;
- статистика отчислений (без ФИО студентов);
- нагрузка преподавателей.

> **Важно:**
> Студенты могут получать только обезличенные данные (количество мест, перечень направлений обучения и т.д.).
>
> Данные других студентов выводятся исключительно в агрегированном или обезличенном виде.


## Примеры бизнес-запросов

### Для приёмной комиссии
- «Сколько заявлений подано на направление "Экономика" в 2026 году?»
- «Какой средний балл ЕГЭ у поступивших в 2025 году?»
- «Сколько бюджетных мест осталось?»

### Для декана
- «Сколько студентов обучается на факультете информационных технологий?»
- «Какой средний GPA по факультету за весенний семестр?»
- «Сколько студентов имеют академическую задолженность?»

### Для преподавателя
- «Сколько студентов записано на курс "Базы данных"?»
- «Какой средний балл по моей дисциплине?»
- «Сколько студентов не сдали экзамен?»

### Для ректората
- «Покажи динамику набора студентов за последние 5 лет»
- «Какая кафедра имеет наибольшую учебную нагрузку?»
- «Какова средняя заполняемость аудиторий?»

### Для студента
- «Какой у меня средний балл за семестр?»
- «Есть ли у меня задолженности?»
- «Какие дисциплины у меня в этом семестре?»

### Для абитуриента
- «Какие направления подготовки есть на факультете информационных технологий?»
- «Сколько бюджетных и платных мест на направление "Экономика"?»
- «Какой был средний проходной балл на юриспруденцию в прошлом году?»
- «До какого числа принимаются документы?»
- «Какая статистика подачи заявлений на это направление за прошлые годы?»
